# Students Database CRUD Application

Python backend to manage student records using FastAPI + SQLite

## Project Objective
Build a Python backend application to manage student records using Create, Read, Update, Delete (CRUD) operations.

## Prerequisites
- Python 3.8+
- pip

## Installation

1. Clone the repository
2. Install dependencies:
```bash
pip install -r requirements.txt
