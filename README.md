# Students CRUD API - FastAPI

Build a Python backend application to manage student records using Create, Read, Update, Delete operations.

### Prerequisites
- Python 3.8+
- pip

### Installation
1. Clone the repository
2. Install dependencies: pip install -r requirements.txt
3. Run: uvicorn app:app --reload

### Endpoints
- POST /students/, GET /students/, GET /students/{id}, PUT, DELETE
- Docs: http://127.0.0.1:8000/docs
